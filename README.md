# MatchUp – Cosmetic Shade Matching Application

## 📱 Overview

MatchUp is a mobile application designed to help users find the most suitable cosmetic shades across different brands. Many makeup users experience difficulty when switching brands due to shade inconsistencies. This application provides a shade matching solution by analyzing users' skin undertones and recommending compatible shades from various cosmetic brands.

This project was developed as part of an undergraduate thesis titled:

**"Perancangan Desain UI/UX Aplikasi Pencocokan Shade Kosmetik Dengan Metode Design Thinking."**

## 🎯 Objectives

* Help users identify their skin undertone.
* Provide cosmetic shade matching across brands.
* Reduce the risk of choosing the wrong shade when switching products.
* Provide educational beauty insights for users.

## 🧠 Features

* **Undertone Test**
  Users answer a series of questions to determine their skin undertone (cool, warm, or neutral).

* **Shade Matching**
  Recommends foundation shades from different brands based on undertone results.

* **Product Details**
  Displays detailed cosmetic product information.

* **Wishlist**
  Users can save favorite products.

* **Beauty Articles**
  Provides educational content about makeup and skincare.

* **User Authentication**
  Login and registration system.

## 🎨 Design Process

The application was designed using the **Design Thinking** methodology:

1. Empathize – User interviews and questionnaires
2. Define – Identifying key user problems
3. Ideate – Designing possible solutions
4. Prototype – UI/UX design in Figma
5. Implementation – Frontend mobile application development
